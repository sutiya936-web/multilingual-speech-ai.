🎙️ Multilingual AI Speech App

 
🌟 Project Overview

This project is an AI-driven speech application that leverages the power of Google AI Studio and Gemini to provide real-time multilingual translation. It was developed using Vibe Coding—a modern approach that focuses on natural language-driven architecture and rapid prototyping.


🛠️ Key Features

Speech-to-Text Integration: Captures audio input and converts it into structured text.
Gemini-Powered Translation: High-accuracy translation across multiple global languages using Google's generative models.
Multilingual Support: Designed to handle diverse dialects and linguistic nuances.
Vibe Coding Workflow: Built through iterative prompt engineering and natural language development for faster deployment.


🧰 Tech Stack

•Model: Google Gemini (via Google AI Studio)
•Language: Python
•Framework: Streamlit (or mention whatever you used, e.g., Flask/FastAPI)
•API: Google Generative AI SDK
